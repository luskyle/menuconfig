# menuconfig++ v0.1.1

用熟悉的图形菜单配置项目宏，生成 CMake 能直接读取的 `sdkconfig`。
源自 Linux 内核的 `kconfig` / `mconf`，在上游 stand-alone mconf 基础上做了中文支持与工程化改造。

## 下载与校验

下载 `menuconfig-0.1.1-linux-x86_64.tar.gz`，解包后包含 `mconf`（图形界面）、`conf`（命令行）、中英文 README 与 LICENSE：

```bash
sha256sum -c menuconfig-0.1.1-linux-x86_64.tar.gz.sha256
tar -xzf menuconfig-0.1.1-linux-x86_64.tar.gz
cd menuconfig-0.1.1 && ./mconf test/rootconf
```

## 环境要求

* Linux x86_64（本预编译包）；从源码构建可跨其它发行版
* 运行时只需要 ncurses：

```bash
sudo apt install -y libncurses6
```

## 功能一览

* **内核同款 TUI**：方向键导航、`<Y>`/`<N>`/`<M>` 开关高亮项、`?` 或 `< Help >` 查看帮助、`/` 搜索
* **中文界面**：链接宽字符版 `ncursesw`，标题、菜单、帮助窗口按**显示列宽**居中与截断，中文项不错位、不被砍成半个字
* **完整 kconfig 语义**：`bool` / `tristate` / `int` / `hex` / `string`、`choice`、`depends on`、`select`、多层子菜单与 `source` 包含
* **输出可直接进构建**：生成 `sdkconfig`（`CONFIG_XXX=y`），CMake 解析后喂给 `add_compile_definitions`
* **非交互模式**：`conf` 提供 `--olddefconfig` / `--defconfig` / `--savedefconfig` / `--allyesconfig` / `--randconfig` 等 12 种模式，可放进脚本与 CI

## 质量保障

本 Release 由 CI 流水线产出，构建前会跑非交互回归（`conf --alldefconfig test/rootconf`），
并校验产物完整性（`.sha256`）。CI 还以 Debug / Release / `DEBUG=OFF` 三组矩阵构建并断言生效的构建类型。

## 已知限制

* **输入框不支持键入/编辑中文**：字符串参数、`/` 搜索、`Save as` 文件名只能用 ASCII 输入；界面**显示**中文已正常。

## English summary

`menuconfig++` v0.1.1 is a **documentation-only release** on top of v0.1.0: bilingual
READMEs (with `README.en.md`), a bilingual project site
(<https://luskyle.github.io/menuconfig-plusplus/en/>), a shared stylesheet, and the
`menuconfig++` branding. No code changed since v0.1.0.

The tarball contains `mconf` (menu UI), `conf` (command line), both READMEs and the
license. Verify with the `.sha256` file next to it.

Known limitation: input boxes do not accept typing/editing CJK text yet — displaying
CJK is fine.
